# Концептуальная архитектура промежуточного решения (онлайн-аукцион через 2 месяца)

## Назначение

Промежуточное решение позволяет провести первый онлайн-аукцион через 2 месяца
**без существенных доработок имеющихся систем и интеграций**:
- вводные готовятся в Excel по утверждённым шаблонам;
- используются имеющиеся ИС для планирования, логистики и проведения аукциона;
- данные публикуются в частном облаке (контракт с провайдером).

## Принцип

Существующие ИС используются **как есть** — без новых функций и доработок.
Новые шаги процесса обеспечиваются **новыми средствами** (Excel-реестры, частное
облако, ИС «Лаборатория») и **ручными интеграциями**. Поэтому на диаграмме:
- всё новое — ➕;
- изменяемых (⚑) нет — существующие системы не дорабатываются;
- выводимых (✗) нет — в промежуточном решении ничего не убираем.

## Легенда

- ➕ зелёный — новое (система / функция / интеграция);
- ⚑ синий — изменяемое (в промежуточном решении не используется);
- ✗ красный — выводимое (в промежуточном решении не используется);
- сплошная стрелка — автоматическая интеграция;
- пунктирная стрелка — ручная интеграция;
- 👤 — роль участника.

## Системы и функции

| Система | Тип | Функции | Пометка |
|---|---|---|---|
| ИС «Алмазы» | существующая | планирование, присвоение ID, подготовка ведомостей | как есть |
| ИС «Логистика» | существующая | перевозка алмазов | как есть |
| ИС «Аукцион» | существующая | проведение аукциона | как есть |
| ИС «Бухгалтерия» | существующая | расчёты, ведение контрактов | как есть |
| Excel-реестры по шаблонам | новая | подготовка вводных для аукциона; реестр описаний | ➕ |
| Частное облако | новая | публикация данных покупателям | ➕ |
| ИС «Лаборатория» | новая | оцифровка алмазов | ➕ |
| Покупатель | роль | просмотр данных, участие в торгах | 👤 |

## Цепочка ценности (процесс)

1. Специалист отбирает камни в ИС «Алмазы» → ведомости выгружаются в Excel (ручная).
2. Логистика отправляет камни в лабораторию (существующей ИС) → лаборатория оцифровывает.
3. Описания из лаборатории попадают в Excel (ручная) → вводные загружаются в ИС «Аукцион» (ручная).
4. Данные лотов из ИС «Аукцион» выгружаются и публикуются в частном облаке (вручную) → покупатель изучает лоты и участвует в торгах.
5. Результаты торгов из ИС «Аукцион» передаются в ИС «Алмазы» (вручную) → «Алмазы» формирует ведомость на отправку → ИС «Логистика» отправляет камни победителю (существующая интеграция).
6. Услуги лаборатории и перевозчика актируются в бухгалтерии.
